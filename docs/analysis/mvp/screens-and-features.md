# MVP Screens & Features

## Home Screen

The Home Screen serves as the main dashboard for the user, providing an overview of key financial metrics, recent activities, and quick access to various sections of the application. It typically includes widgets, summaries, and navigation elements to facilitate efficient management of financial data.

**Key Features:**
- Overview of financial metrics (e.g., total revenue, total expenses, budget status)
- Recent activities and notifications
- Quick access to invoices, payments, and transactions
- Navigation to other sections such as Reports, Plans, and Settings
- Access to user profile and account settings
- Notifications and alerts for important financial events

## Financial Overview Screen

The Financial Overview Screen provides a comprehensive view of the user's financial status, including summaries of revenue, expenses, budgets, and other key financial metrics. It helps users monitor their financial health and make informed decisions.

**Key Features:**
- Summary of total revenue, total expenses, and budget status
- Visual representations such as charts and graphs for financial trends
- Quick access to detailed reports and financial statements
- Notifications and alerts for significant financial changes
- Navigation to related sections such as Expenses, Revenues, Plans, Invoices, and Payments
- Import process from CSV or Excel with bank statement mapping

## Expenses Screen

The Expenses Screen allows users to view, manage, and track their expenses. It provides a centralized location for accessing expense details, status, and related financial information.

**Key Features:**
- List of all expenses with search and filter options
- View detailed expense information including amounts, dates, and status
- Track expense history for each entry
- Create, edit, and delete expenses
- Notifications and reminders for upcoming or overdue expenses
- Navigation to related sections such as Financial Overview, Invoices, and Payments
- Import expenses from external sources such as CSV or Excel files
- Import invoices from PDF or other supported formats

## Invoices Screen

The Invoices Screen allows users to view, manage, and track their invoices. It provides a centralized location for accessing invoice details, payment status, and related financial information.

**Key Features:**
- List of all invoices with search plus status, date-range, and total-amount-range filters, Transaction-list-style sorting/pagination, and a clear-filters action
- Invoices categorized by status (e.g., paid, unpaid, overdue), type (e.g., service, product) and if it's incoming or outgoing
- View detailed invoice information including service/product type, items, amounts, VAT, and due dates
- Track payment status and history for each invoice
- Create a draft invoice with one or more itemized lines; show live line and aggregate net/VAT/total previews, with the server as the authoritative calculation on save
- Edit only a draft invoice through a prepopulated dedicated form reached from its details view; retain counterparty, direction, and type as immutable context while allowing invoice/due dates and complete itemized line collection to change
- Add and remove draft line items in the creation/edit form; cancellation returns without persistence, and a successful save refreshes invoice list and detail data
- Delete an accidental draft invoice after confirmation only when it has no attached Payment; this permanently removes the draft and is distinct from archival
- Archive an issued, overdue, or void invoice after confirmation only when it is not paid and has no attached Payment; archived invoices are hidden by default
- Open the generated invoice PDF from a document-icon row action in a new browser tab
- Attach, view, replace, or remove one PDF, PNG, or JPEG source document (maximum 10 MB) from the invoice details view
- Notifications and reminders for upcoming or overdue invoices
- Navigation to related sections such as Payments and Financial Overview
